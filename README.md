# FIKRA AI

**Production-grade, multi-tenant RAG chatbot — runs 100% locally with no recurring costs.**

Organizations upload documents → users ask questions → grounded answers with validated citations powered by Groq (free tier) and a local embedding model (BGE-small).

---

## Quick start (local dev, zero setup)

### 1. Prerequisites

- Docker Desktop 4.x+
- Python 3.12 (via `uv` or python.org)
- Node.js 20 LTS

### 2. Configure environment

```powershell
Copy-Item backend\.env.example backend\.env
```

Edit `backend\.env` and set:
- `GROQ_API_KEY` — free key at [https://console.groq.com](https://console.groq.com)
- `SECRET_KEY` / `JWT_SECRET_KEY` — generate with:
  ```powershell
  python -c "import secrets; print(secrets.token_hex(64))"
  ```
- `DATA_ENCRYPTION_KEY` — auto-generated by `setup.ps1`, or run:
  ```powershell
  python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
  ```

### 3. Setup (PowerShell from repo root)

```powershell
.\setup.ps1          # installs deps, migrates DB, seeds org, starts services
```

### 4. Start the stack

```powershell
docker compose up -d        # postgres, redis, qdrant
cd backend && ..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
cd backend && ..\.venv\Scripts\python.exe -m celery -A app.workers.celery_app worker --loglevel=info -Q default,ingestion
cd frontend && npm.cmd install --legacy-peer-deps && npm.cmd run dev
```

Open **http://localhost:3000** — Login: `admin@fikra.ai` / `Admin1234!` (change immediately)

## Production server deploy (your own VM)

One command to deploy to any Ubuntu 22.04+ server with a domain:

```bash
sudo ./scripts/deploy-free-server.sh your-domain.com your-groq-api-key
```

See [`docs/operations/server-deployment.md`](docs/operations/server-deployment.md) for the full manual reference.

### What's deployed

| Layer | Technology | Cost |
|-------|-----------|------|
| **LLM** | Groq `llama-3.1-8b-instant` → `openai/gpt-oss-20b` fallback | Free tier |
| **Embeddings** | BGE-small (~130 MB) — runs on any server | Free |
| **Vector store** | Qdrant (Docker) | Free |
| **Database** | PostgreSQL 16 (Docker) | Free |
| **Cache/Broker** | Redis 7 (Docker) | Free |
| **Backend** | FastAPI + Celery | Free |
| **Frontend** | Next.js | Free |
| **SSL** | Let's Encrypt via Nginx + Certbot | Free |

**Groq fallback:** if the primary model hits its token limit, the backend automatically tries the fallback model with exponential backoff — you never see an error.

## Security (built in)

| Feature | How it works |
|---------|--------------|
| **Password encryption** | Argon2id hashing — never stored in plaintext |
| **Data encryption at rest** | Sensitive fields encrypted with Fernet before hitting PostgreSQL |
| **Encryption key** | `DATA_ENCRYPTION_KEY` in `backend/.env` (auto-generated by deploy scripts) |
| **Token auth** | JWT access tokens in HttpOnly cookies + rotating refresh tokens |
| **HTTPS** | Let's Encrypt certificate via Nginx + Certbot |

> `users.email_normalized` stays plaintext on purpose — login queries by it. Document chunk content stays plaintext because PostgreSQL full-text search indexes it directly.

## Architecture

```
Browser → Next.js → FastAPI → PostgreSQL (schema + full-text)
                             → Qdrant (vector search)
                             → Redis (Celery queue + rate limits)
                             → Groq API (LLM)
                  Celery Worker → Storage → Embeddings → Qdrant
```

- **Multi-tenant**: Every resource is scoped to an organization. Cross-tenant access is impossible through the API.
- **RAG pipeline**: Hybrid retrieval (Qdrant cosine + PostgreSQL FTS) → RRF fusion → optional cross-encoder reranking → bounded prompt → Groq generation → server-validated citations.
- **Secure auth**: Argon2id passwords, JWT in HttpOnly cookies, refresh token rotation.

Full documentation: [`docs/`](docs/)

## Key configuration

| Variable | Required | Description |
|----------|----------|-------------|
| `LLM_PROVIDER` | No | `groq` (default) |
| `GROQ_API_KEY` | Groq only | Free Groq API key |
| `GROQ_PRIMARY_MODEL` | No | `llama-3.1-8b-instant` |
| `GROQ_FALLBACK_MODEL` | No | `openai/gpt-oss-20b` (auto-fallback) |
| `DATA_ENCRYPTION_KEY` | Production | Fernet key (generate with `cryptography`) |
| `SECRET_KEY` | ✅ | App secret (64-byte hex) |
| `JWT_SECRET_KEY` | ✅ | JWT signing secret (64-byte hex) |
| `DATABASE_URL` | ✅ | PostgreSQL async connection string |
| `REDIS_URL` | No | Redis connection |
| `ALLOWED_ORIGINS` | Production | JSON array of allowed origins |

Full reference: [`docs/operations/configuration-reference.md`](docs/operations/configuration-reference.md)
